# Gia para programadores

Guía de estudio en español para aprender a programar y a trabajar como programador, con ejemplos listos para copiar.

La idea es consultar todo desde una página web (`index.html`) con un buscador para encontrar cada lenguaje y cada tema.

## Contenido

Cada tema tiene su propia carpeta:

| Carpeta | Tema |
|---|---|
| `git-github/` | Git y GitHub, de lo más básico a lo avanzado: trabajo en solitario con IA, trabajo en equipo y revisión de cambios |
| `cmd/` | Cómo usar la consola (CMD y PowerShell) |
| `cpp/` | C++: comentarios, entrada y salida por consola, arreglos, colas, `for`, `while`, `do while` y matrices |
| `arduino/` | Arduino IDE y todo lo necesario para empezar y avanzar con Arduino |
| `python/` | Python desde cero |
| `javascript/` | JavaScript desde cero |
| `desarrollo-web/` | HTML y CSS con estilo profesional, animaciones de texto y más |
| `ia-para-programar/` | Cómo usar la IA para programar y lograr que los programas salgan bien |

## Estado

## Cómo usarla

Cuando la página esté lista, basta con abrir `index.html` en el navegador. No necesita internet ni instalar nada.
