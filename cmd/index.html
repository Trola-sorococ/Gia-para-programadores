¿Qué es la consola y cómo abrirla?

La consola (también llamada terminal, shell o “símbolo del sistema”) es una ventana donde escribes comandos de texto y Windows los ejecuta. No sustituye al Explorador de archivos: es otra forma de hablarle a la computadora, muy útil cuando programas, instalas herramientas o quieres hacer algo repetitivo sin hacer clic mil veces.

  • Cambiar de carpeta, crear archivos y copiar proyectos.
  • Ejecutar programas como Git, Python, Node o el compilador de C++.
  • Ver errores con más detalle que en una ventana gráfica.
  • Automatizar tareas con scripts (.bat o PowerShell).
No necesitas memorizar todo

Con unos pocos comandos (cd, dir/ls, mkdir, copiar/pegar rutas) ya te mueves. El resto lo consultas aquí cuando lo necesites. Los mensajes de error a veces salen en inglés; en esta guía te explico los más comunes.

Windows Terminal (recomendado)

Si puedes, usa Windows Terminal: una sola app con pestañas para CMD, PowerShell y más. Suele venir en Windows 11; en Windows 10 puedes instalarla desde la Microsoft Store o con:

winget install --id Microsoft.WindowsTerminal -e

Dentro de Terminal, el botón + o la flecha junto a él te deja elegir el perfil (PowerShell, Símbolo del sistema, etc.).

Qué vas a ver al abrirla

Una línea de texto (el prompt) te indica dónde estás. En CMD suele verse así:

C:\Users\TuNombre>

En PowerShell es parecido, a veces con PS al inicio:

PS C:\Users\TuNombre>

Esa ruta es tu carpeta actual. Los comandos que escribas actúan ahí, salvo que indiques otra ruta.

Cuál elegir al empezar

Para esta guía puedes usar las dos. Si no sabes por dónde empezar: abre PowerShell (o Windows Terminal con perfil PowerShell). Entiende casi todo lo de CMD y tiene comandos más modernos. En la siguiente sección comparamos las dos.

¿Puedo mezclar comandos?

A menudo sí. En PowerShell muchos comandos de CMD siguen funcionando (cd, mkdir, cls, ipconfig…). Pero no al revés: cosas como Get-ChildItem o $env:PATH son de PowerShell y en CMD fallan.

Mira el prompt antes de copiar un comando

Si un tutorial dice “abre PowerShell” y pegas un comando con $ o Get- en CMD, no va a funcionar. Si dice “CMD” y usas sintaxis rara de PowerShell, tampoco. En esta guía marco las diferencias cuando importan.

PowerShell clásico vs PowerShell 7

  • Windows PowerShell 5.1 viene instalado en Windows 10/11 (icono azul).
  • PowerShell 7+ (pwsh) se instala aparte; es más nuevo y multiplataforma. No es obligatorio para esta guía.

Para empezar, el PowerShell que ya trae Windows basta.

Resumen práctico

  1. Estudia los comandos básicos en cualquiera de las dos.
  2. Prefiere PowerShell cuando puedas.
  3. Usa CMD si un tutorial o un .bat lo exige.

Moverte entre carpetas

Lo primero que necesitas es saber dónde estás y cómo cambiar de carpeta. Sin eso, cada comando “no encuentra” archivos que sí existen… en otra ruta.

Ver la carpeta actual

En CMD:

cd

En PowerShell también puedes usar:

pwd
C:\Users\TuNombre\Documents

dir y ls: listar el contenido

En CMD el comando clásico es dir:

dir
dir /b

/b muestra solo los nombres (vista corta). En PowerShell puedes usar dir, ls o el nombre largo Get-ChildItem (los tres listan archivos y carpetas):

ls
Get-ChildItem

----                 -------------         ------ ----

-a----        10/11/2026     18:22           1204 notas.txt

cd: cambiar de carpeta

cd Documentos
cd "Mis proyectos"
cd C:\Users\TuNombre\Desktop
  • Si el nombre tiene espacios, ponlo entre comillas.
  • Puedes pegar una ruta copiada del Explorador (clic en la barra de dirección y Ctrl + C).

Cambiar de unidad (C:, D:, …)

En Windows cada disco es una letra. En CMD, cambiar de unidad no es solo un cd: primero escribes la letra:

D:
cd D:\Proyectos\curso

En PowerShell basta con:

cd D:\Proyectos\curso
Ruta absoluta vs relativa

Una ruta absoluta empieza por la unidad (C:\Users\...) y funciona desde cualquier sitio. Una ruta relativa parte de donde estás ahora (cd carpeta, cd ..\otra). Usa absolutas cuando no quieras dudar; relativas cuando ya estás cerca.

Truco del Explorador

Navega con el ratón hasta la carpeta del proyecto, haz clic en la barra de dirección, escribe powershell (o cmd) y pulsa Enter. La consola abre ya en el sitio correcto.

Crear, copiar, mover y borrar

Estos comandos hacen lo mismo que el Explorador, pero desde el teclado. Practica primero en una carpeta de prueba para no tocar proyectos importantes.

Borrar desde la consola no usa la Papelera

del, rmdir, Remove-Item y similares eliminan de verdad. Revisa dos veces la ruta y el nombre antes de pulsar Enter.

Crear carpetas: mkdir

Funciona en CMD y PowerShell (en CMD también existe el alias md):

mkdir practica
mkdir practica\entrada practica\salida

En PowerShell el nombre largo es New-Item -ItemType Directory -Name practica; para el día a día mkdir basta.

Crear un archivo vacío o con texto

En CMD puedes crear un archivo vacío así:

type nul > practica\hola.txt

En PowerShell:

New-Item practica\hola.txt
Set-Content practica\hola.txt "Hola desde PowerShell"

Copiar: copy / Copy-Item

copy practica\hola.txt practica\hola-copia.txt

Equivalente en PowerShell:

Copy-Item practica\hola.txt practica\hola-copia.txt
Copy-Item practica\entrada\* practica\salida\ -Recurse

-Recurse copia también subcarpetas. En CMD, para carpetas enteras se usa a menudo xcopy o robocopy (más potentes; robocopy es el recomendado en Windows moderno).

robocopy practica\entrada practica\salida /E

Mover o renombrar: move / Move-Item

Mover y renombrar son la misma idea: cambias la ruta o el nombre.

move practica\hola.txt practica\entrada\
move practica\entrada\hola.txt practica\entrada\saludo.txt

En PowerShell:

Move-Item practica\hola.txt practica\entrada\
Rename-Item practica\entrada\hola.txt saludo.txt

Borrar archivos: del / Remove-Item

del practica\hola-copia.txt
del practica\entrada\*.tmp

En PowerShell:

Remove-Item practica\hola-copia.txt
Remove-Item practica\entrada\*.tmp

El asterisco * es un comodín: *.tmp son todos los archivos que terminan en .tmp.

Borrar carpetas: rmdir / rd

En CMD, una carpeta vacía:

rmdir practica\salida

Si tiene archivos dentro, hace falta borrar en cascada (cuidado):

rmdir /s /q practica
  • /s borra también el contenido.
  • /q no pide confirmación.

En PowerShell:

Remove-Item practica -Recurse -Force
Empieza sin /q ni -Force

Así Windows te pregunta o tú puedes cancelar si te equivocaste de carpeta. Reserva el modo “silencioso” para cuando estés seguro.

Ver y buscar contenido

Cuando programas, pasas mucho tiempo leyendo archivos de texto, buscando un error en un log o comprobando si un programa está instalado. Estos comandos cubren eso.

type y Get-Content: ver un archivo

En CMD:

type notas.txt
type C:\Users\TuNombre\Documents\notas.txt

En PowerShell (parecido a cat en otros sistemas):

Get-Content notas.txt
cat notas.txt
Recordatorio: terminar la guía de CMD
Probar git status mañana

more: ver página a página

Si el archivo es largo, type se te escapa por la pantalla. Con more avanzas con la barra espaciadora:

more notas.txt
type largo.log | more

En PowerShell también puedes usar more, o:

Get-Content largo.log | more

Pulsa q o Ctrl + C si quieres salir antes de terminar.

findstr y Select-String: buscar texto

En CMD, findstr busca una palabra dentro de archivos:

findstr "error" app.log
findstr /i /s "TODO" *.txt *.js
  • /i ignora mayúsculas/minúsculas.
  • /s busca también en subcarpetas.

En PowerShell el equivalente moderno es Select-String:

Select-String -Path app.log -Pattern "error"
Select-String -Path *.txt,*.js -Pattern "TODO" -CaseSensitive:$false
app.log:42:Error: archivo de configuración no encontrado
app.log:88:Error: tiempo de espera agotado
Si vienes de Linux o macOS

findstr / Select-String hacen un papel parecido a grep. No son idénticos, pero para “buscar esta palabra en estos archivos” te sirven.

where: ¿dónde está este programa?

Muy útil cuando Windows dice que “no se reconoce el comando” o tienes varias versiones instaladas:

where python
where git
where node
C:\Users\TuNombre\AppData\Local\Programs\Python\Python312\python.exe
C:\Users\TuNombre\AppData\Local\Microsoft\WindowsApps\python.exe

En PowerShell también existe Get-Command:

Get-Command python
Get-Command git | Format-List *

Te dice qué ejecutable se usará y de qué carpeta sale (relacionado con el PATH, que veremos más adelante).

Atajos y trucos

La consola se vuelve cómoda cuando dejas de reescribir rutas a mano. Estos atajos ahorran tiempo desde el primer día.

Tab: autocompletar

Empieza a escribir el nombre de un archivo o carpeta y pulsa Tab. Windows completa el resto. Si hay varias opciones, pulsa Tab otra vez para ciclar entre ellas.

cd Doc<Tab>
cd Gia<Tab>
Nombres con espacios

Al autocompletar, la consola suele poner comillas sola ("Mis documentos"). Si escribes a mano, no olvides las comillas.

Flechas: historial de comandos

  • ↑ y ↓: recuperan comandos que ya ejecutaste.
  • ← y →: mueven el cursor para editar la línea.
  • En PowerShell / Windows Terminal, F7 a veces muestra una lista del historial (según configuración).

También puedes marcar texto con el ratón y copiar/pegar con Ctrl + C / Ctrl + V en Windows Terminal y PowerShell modernos. En CMD antiguo, a veces hace falta clic derecho para pegar.

Limpiar la pantalla: cls / clear

cls

En PowerShell también funciona Clear-Host y, en muchos perfiles, clear. No borra archivos: solo limpia lo que ves en la ventana.

Ctrl + C: cancelar

Si un comando se queda “colgado” (un servidor, un ping infinito, un script), pulsa Ctrl + C para interrumpirlo y volver al prompt.

Ctrl+C no es “copiar” cuando un comando está corriendo

Con un proceso activo, Ctrl + C lo cancela. Para copiar texto seleccionado en Terminal moderno usa Ctrl + C solo cuando no hay un comando en ejecución, o el menú / clic derecho según tu configuración.

Más atajos útiles

AtajoPara qué sirve
Ctrl + LEn muchas consolas modernas, limpia la pantalla (como cls).
Ctrl + ← / →Salta de palabra en palabra al editar.

Ayuda rápida de un comando

dir /?
cd /?
Get-Help Get-ChildItem -Examples

El /? es el estilo CMD. En PowerShell, Get-Help (o -?) da la documentación del comando.

Variables de entorno y PATH

Las variables de entorno son valores que Windows guarda y que los programas pueden leer: tu nombre de usuario, la carpeta temporal, el idioma… La más importante para programar es PATH.

Qué es el PATH

El PATH es una lista de carpetas. Cuando escribes un comando (git, python, node), Windows busca un ejecutable con ese nombre en esas carpetas, en orden. Si lo encuentra, lo ejecuta. Si no, aparece el mensaje temido:

"git" no se reconoce como un comando interno o externo,
programa o archivo por lotes ejecutable.

En PowerShell el mensaje suele ser:

git : El término 'git' no se reconoce como nombre de un cmdlet,
función, archivo de script o programa ejecutable.

Casi siempre significa una de estas tres cosas:

  1. El programa no está instalado.
  2. Está instalado, pero su carpeta no está en el PATH.
  3. Está en el PATH, pero no has cerrado y vuelto a abrir la consola después de instalarlo.

Ver el PATH actual

En CMD:

echo %PATH%

En PowerShell:

$env:PATH
$env:PATH -split ';'

La segunda forma lo muestra carpeta por carpeta (más legible).

Cómo arreglar “no se reconoce el comando”

  1. Comprueba si está instalado: busca el programa en el menú Inicio o vuelve a instalarlo.
  2. Cierra todas las ventanas de consola y abre una nueva (el PATH se lee al iniciar).
  3. Si sigue fallando, localiza el .exe (por ejemplo con el Explorador) y mira si su carpeta está en el PATH.
  4. Para añadirlo de forma permanente: Configuración → Sistema → Acerca de → Configuración avanzada del sistema → Variables de entorno. Edita Path (de tu usuario o del sistema), agrega la carpeta, acepta, y abre una consola nueva.
Comprueba con where

Después de instalar o tocar el PATH, ejecuta where git (o python, node…). Si imprime una ruta a un .exe, Windows ya lo encuentra.

No borres entradas del PATH a ciegas

Quitar carpetas del PATH puede romper programas. Añade lo que falte; no limpies la lista “por ordenar” sin saber qué hace cada ruta.

Redirecciones y pipes

Por defecto, la salida de un comando se imprime en pantalla. Con redirecciones la mandas a un archivo; con un pipe (|) se la pasas a otro comando.

Guardar la salida: > y >>

  • > crea el archivo o lo sobrescribe si ya existía.
  • >> añade al final sin borrar lo anterior.
dir > lista.txt
echo Primera linea > notas.txt
echo Segunda linea >> notas.txt
Primera linea
Segunda linea

(El contenido de notas.txt tras los dos echo.)

Un solo > borra el contenido previo

Si quieres conservar lo que ya había en el archivo, usa >>. Reserva > para cuando quieras empezar de cero.

Pipe: |

El símbolo | conecta la salida de un comando con la entrada del siguiente. Ejemplo clásico: listar y buscar a la vez.

dir /b | findstr "html"
ipconfig | findstr "IPv4"

En PowerShell:

Get-ChildItem | Select-String "html"
Get-ChildItem | Where-Object { $_.Name -like "*.html" }
ipconfig | Select-String "IPv4"
   Dirección IPv4. . . . . . . . . . . . . . : 192.168.1.20

Combinar ideas

ipconfig > red.txt
type red.txt | findstr "IPv4"
dir /b *.md > lista-md.txt

Patrón mental: comando → (opcional) filtrar con | → (opcional) guardar con > / >>.

Errores y salida estándar (idea breve)

Algunos programas escriben mensajes normales por un canal y errores por otro. En CMD puedes redirigir errores con 2>:

comando_que_falla 2> errores.txt
comando > todo.txt 2>&1

La segunda forma junta salida normal y errores en el mismo archivo. No hace falta memorizarlo al principio; basta saber que existe cuando un log “no guarda” los mensajes rojos.

Procesos y red

Cuando un programa no responde, el puerto está ocupado o “no hay internet”, la consola te da pistas rápidas sin instalar nada.

tasklist: qué está corriendo

tasklist
tasklist | findstr "chrome"
Nombre de imagen                     PID Nombre de sesión Núm. de ses Memoria
========================= ======== ================ =========== ============
chrome.exe                    12345 Console                    1    250,000 K
chrome.exe                    12346 Console                    1    180,000 K

El PID es el número de proceso. Lo necesitas para cerrarlo a propósito.

En PowerShell:

Get-Process
Get-Process chrome -ErrorAction SilentlyContinue

taskkill: cerrar un proceso

taskkill /PID 12345
taskkill /IM notepad.exe
taskkill /PID 12345 /F
  • /IM usa el nombre de la imagen (el .exe).
  • /F fuerza el cierre (cuando no responde).

En PowerShell:

Stop-Process -Id 12345
Stop-Process -Name notepad -Force
No mates procesos al azar

Cerrar el proceso equivocado puede perder trabajo sin guardar o dejar el sistema inestable. Úsalo cuando sepas qué estás cerrando (un editor colgado, un servidor de desarrollo, etc.).

ipconfig: tu configuración de red

ipconfig
ipconfig /all

Lo más buscado al principio: la dirección IPv4 de tu PC en la red local (algo como 192.168.x.x) y si el adaptador Wi‑Fi o Ethernet está conectado.

ipconfig | findstr "IPv4"

ping: ¿llega la red hasta allí?

ping 8.8.8.8
ping google.com
ping -n 4 127.0.0.1
  • 8.8.8.8 es un DNS público de Google: si responde, hay salida a internet (salvo firewalls raros).
  • google.com prueba también la resolución de nombres (DNS).
  • 127.0.0.1 es “esta misma máquina” (localhost).
  • -n 4 envía solo 4 ecos (si no, en algunos casos sigue hasta que canceles con Ctrl + C).
Haciendo ping a google.com [142.250.x.x] con 32 bytes de datos:
Respuesta desde 142.250.x.x: bytes=32 tiempo=18ms TTL=116
...
Estadísticas de ping para 142.250.x.x:
    Paquetes: enviados = 4, recibidos = 4, perdidos = 0 (0% perdidos)
Ping no lo es todo

Algunos servidores bloquean el ping y aun así la web funciona. Si falla el ping pero el navegador carga, no asumas que “no hay red”.

Scripts .bat

Un archivo .bat (batch / “por lotes”) es un bloc de notas con comandos de CMD, uno tras otro. Al hacer doble clic o al ejecutarlo desde la consola, Windows los corre en orden. Sirve para automatizar lo que siempre repites.

Tu primer .bat

  1. Abre el Bloc de notas.
  2. Escribe los comandos.
  3. Guarda como hola.bat (en “Tipo”, elige Todos los archivos para que no quede en .txt).
  4. Ejecútalo con doble clic o desde la consola: hola.bat.
@echo off
echo Hola desde un script bat
cd /d %USERPROFILE%\Documents
dir /b
pause
  • @echo off oculta la eco de cada línea (la pantalla se lee mejor).
  • cd /d cambia de carpeta y de unidad si hace falta.
  • pause espera una tecla: útil si abriste el .bat con doble clic (si no, la ventana se cierra al terminar).

Variables y parámetros

@echo off
set NOMBRE=Ada
echo Hola, %NOMBRE%

REM %1 es el primer argumento al llamar el script
echo Primer argumento: %1

Si guardas eso como saludo.bat y ejecutas:

saludo.bat Mundo
Hola, Ada
Primer argumento: Mundo

Ejemplo práctico: preparar una carpeta de proyecto

@echo off
set NOMBRE=%1
if "%NOMBRE%"=="" (
  echo Uso: nuevo-proyecto.bat nombre-del-proyecto
  exit /b 1
)
mkdir "%NOMBRE%"
mkdir "%NOMBRE%\src"
mkdir "%NOMBRE%\docs"
echo # %NOMBRE%> "%NOMBRE%\README.md"
echo Proyecto "%NOMBRE%" creado.
pause

Consejos para no sufrir

  • Pon rutas con espacios entre comillas: "C:\Mis documentos\proyecto".
  • Prueba primero los comandos a mano en CMD; cuando funcionen, pégalos en el .bat.
  • Comenta con REM o :: lo que no sea obvio.
¿Y PowerShell?

Los scripts de PowerShell usan extensión .ps1 y otra sintaxis. Windows a veces bloquea su ejecución por política de seguridad; los .bat son más simples para empezar. Cuando te quedes corto, el siguiente paso natural es aprender .ps1.

No ejecutes .bat de desconocidos

Un script puede borrar archivos o instalar cosas. Abre el archivo en el Bloc de notas y léelo antes de ejecutarlo si no lo escribiste tú.

Comandos que usarás al programar

La consola es el sitio donde compruebas que tus herramientas están instaladas y donde las ejecutas día a día. El patrón casi siempre es el mismo: programa --version (o -v) para verificar, y luego el comando de trabajo.

Comprobar que existen

git --version
python --version
node --version
npm --version
g++ --version
git version 2.47.1.windows.1

v22.11.0

Si alguno falla con “no se reconoce”, vuelve a la sección del PATH: instala el programa, cierra y abre la consola, y prueba where nombre.

Python en Windows

A veces python abre la Microsoft Store o no está en el PATH, y el comando real es py. Prueba también:

py --version
py -3 --version

Git

Control de versiones. Ciclo mínimo cuando ya tienes un repositorio:

git status
git add .
git commit -m "Describe el cambio"
git push

Para clonar un proyecto:

git clone https://github.com/usuario/repositorio.git
cd repositorio

La guía completa está en el tema Git y GitHub de este sitio.

Python

python archivo.py
py archivo.py
python -m venv .venv
.\.venv\Scripts\activate

El último bloque crea y activa un entorno virtual en PowerShell/CMD (en PowerShell a veces hace falta permitir scripts la primera vez). Con el entorno activo, pip install instala paquetes solo ahí.

Node.js y npm

node archivo.js
npm -v
npm init -y
npm install
npm run start
  • node ejecuta JavaScript.
  • npm instala paquetes y corre scripts definidos en package.json.

g++ (C++)

Si tienes MinGW, MSYS2 o similar en el PATH:

g++ --version
g++ main.cpp -o main.exe
.\main.exe

El primer comando confirma el compilador; el segundo genera el ejecutable; el tercero lo corre desde la carpeta actual.
