¿Qué es JavaScript y dónde se ejecuta?

JavaScript es el lenguaje que hace que las páginas web reaccionen: botones que responden, formularios que se validan, menús que se abren, datos que se cargan sin recargar la página. Nació para el navegador y hoy también se usa fuera de él.

  • En el navegador (Chrome, Firefox, Edge…): controla el HTML y el CSS, escucha clics y pide datos a un servidor.
  • En Node.js: ejecuta JavaScript en tu computadora o en un servidor, sin abrir una ventana del navegador. Sirve para scripts, APIs, herramientas y mucho más.

JavaScript no es Java

El nombre se parece, pero son lenguajes distintos. JavaScript (a veces abreviado JS) es el de la web. El estándar oficial se llama ECMAScript (ES6, ES2020…); cuando alguien dice “JS moderno”, suele referirse a esas versiones.

Qué necesitas para empezar

  1. Un navegador actual (ya lo tienes) y la tecla F12 para abrir las DevTools.
  2. Un editor de texto: Visual Studio Code, Cursor u otro similar.
  3. Opcional al principio: Node.js, para correr scripts desde la terminal. Descárgalo en nodejs.org (versión LTS).
Empieza en el navegador

Puedes aprender variables, funciones y arrays sin instalar nada. Node.js te será útil cuando llegues a módulos, npm y scripts fuera de la web.

Qué vas a encontrar en esta guía

  1. Lo básico: primer programa, variables, operadores, bucles y funciones.
  2. Datos: arrays, objetos y JSON.
  3. La web: DOM, eventos, asincronía y fetch.
  4. Organización: módulos, npm y cómo depurar con las DevTools.
  5. Al final, ideas de proyectos para practicar.

Tu primer programa

El clásico “Hola, mundo” en JavaScript se escribe con console.log: muestra un mensaje en la consola.

1. En la consola del navegador

Abre cualquier página, pulsa F12 (o clic derecho → Inspeccionar), ve a la pestaña Consola y escribe:

console.log("Hola, mundo");

Pulsa Enter. Deberías ver:

Hola, mundo

2. En un archivo HTML con <script>

Crea una carpeta, por ejemplo hola-js, y dentro un archivo index.html:

<!DOCTYPE html>
<html lang="es">
<head>
  <meta charset="utf-8">
  <title>Hola JavaScript</title>
</head>
<body>
  <h1>Abre la consola (F12)</h1>
  <script>
    console.log("Hola desde el HTML");
  </script>
</body>
</html>

Ábrelo con doble clic o arrástralo al navegador. En la consola verás el mensaje.

Mejor un archivo .js aparte

Cuando el código crece, sepáralo: <script src="app.js"></script> al final del body. Así el HTML queda limpio y el JS se puede reutilizar.

<script src="app.js"></script>
console.log("Hola desde app.js");
const nombre = "Ana";
console.log("Bienvenida,", nombre);

3. Con Node.js en la terminal

Si ya instalaste Node, comprueba la versión:

node --version

Crea hola.js y ejecútalo:

console.log("Hola desde Node.js");
node hola.js
Hola desde Node.js
console.log no es solo para saludar

Es tu mejor amigo al aprender: imprime variables, resultados de cálculos y mensajes para saber qué está pasando. Más adelante verás cómo depurar con breakpoints.

Variables y tipos de datos

Una variable es un nombre que guarda un valor. En JavaScript moderno usas let (puede cambiar) y const (no se reasigna).

let y const

let edad = 20;
edad = 21; // bien: let se puede reasignar

const PI = 3.1416;
// PI = 3; // Error: no puedes reasignar una const

const usuario = { nombre: "Luis" };
usuario.nombre = "Ana"; // bien: el objeto sí puede mutar
// usuario = {}; // Error: no puedes cambiar la referencia
Evita var

var es la forma antigua. Tiene reglas de alcance confusas (function scope, hoisting). En código nuevo usa solo let y const. Prefiere const por defecto y let cuando realmente necesites reasignar.

== versus ===

== compara con conversión de tipos (puede sorprenderte). === compara valor y tipo sin convertir. Usa siempre === y !==.

console.log(5 == "5");   // true  (convierte el string a número)
console.log(5 === "5");  // false (number !== string)

console.log(0 == false);  // true
console.log(0 === false); // false

console.log(null == undefined);  // true
console.log(null === undefined); // false
Regla de oro

Escribe siempre === / !==. Si algún día necesitas conversión, hazla tú a propósito (Number(x), String(x)), no dejes que == lo haga a escondidas.

Operadores y condicionales

Los operadores combinan valores; los condicionales eligen qué camino seguir según una condición.

Operadores útiles

const a = 10;
const b = 3;
console.log(a + b);  // 13

const nota = 7;

} else {

Operador ternario

Es un if en una sola expresión: condicion ? siVerdadero : siFalso.

const edad = 17;
const mensaje = edad >= 18 ? "Mayor de edad" : "Menor de edad";
console.log(mensaje);
Cuándo usarlo

Ideal para asignar un valor corto. Si hay varias ramas o mucho código, usa if/else: se lee mejor.

switch

Útil cuando comparas una misma variable contra varios valores fijos. No olvides el break (si no, “cae” al siguiente caso).

const dia = "jueves";

switch (dia) {
  case "lunes":
  case "martes":
  case "miércoles":
  case "jueves":
  case "viernes":
    console.log("Día laboral");
    break;
  case "sábado":
  case "domingo":
    console.log("Fin de semana");
    break;
  default:
    console.log("Día no válido");
}

Bucles

Un bucle repite un bloque de código mientras se cumpla una condición o mientras queden elementos por recorrer.

for

for (let i = 0; i < 5; i++) {
  console.log("Vuelta", i);
}
// Vuelta 0 … Vuelta 4

while y do…while

while comprueba la condición antes de entrar. do…while ejecuta al menos una vez y comprueba después.

let n = 3;
while (n > 0) {
  console.log(n);
  n--;
}

let clave;
do {
  // En el navegador podrías usar prompt(); aquí simulamos:
  clave = "ok";
  console.log("Intentando…");
} while (clave !== "ok");

for…of (recorrer valores)

Ideal para arrays y strings: te da cada valor.

const frutas = ["manzana", "pera", "uva"];

for (const fruta of frutas) {
  console.log(fruta);
}

for (const letra of "hola") {
  console.log(letra);
}

for…in (recorrer claves)

Recorre las propiedades de un objeto (las claves). En arrays da los índices como strings; para arrays prefiere for…of o métodos como forEach/map.

const persona = { nombre: "Eva", edad: 30, ciudad: "Lima" };

for (const clave in persona) {
  console.log(clave, "→", persona[clave]);
}
break y continue

break sale del bucle por completo. continue salta a la siguiente iteración. Úsalos con moderación: a veces un if claro dentro del bucle se entiende mejor.

for (let i = 1; i <= 10; i++) {
  if (i === 3) continue; // salta el 3
  if (i === 8) break;    // para en el 8
  console.log(i);
}

Funciones

Una función empaqueta un trozo de lógica con un nombre (o sin él), recibe datos (parámetros) y puede devolver un resultado con return.

Declaración de función

function saludar(nombre) {
  return `Hola, ${nombre}`;
}

console.log(saludar("Carlos")); // "Hola, Carlos"

Expresión de función

Guardas la función en una variable. No se “eleva” como la declaración (no puedes usarla antes de esa línea).

const sumar = function (a, b) {
  return a + b;
};

console.log(sumar(2, 3)); // 5

Funciones flecha

Sintaxis corta, muy usada en callbacks y código moderno.

const multiplicar = (a, b) => a * b;
const alCuadrado = (x) => x * x;
const avisar = () => console.log("Listo");

console.log(multiplicar(4, 5)); // 20
console.log(alCuadrado(6));     // 36
avisar();
return implícito

Si el cuerpo es una sola expresión sin llaves, la flecha devuelve ese valor. Con llaves { } necesitas return explícito.

Parámetros por defecto y rest

function presentar(nombre = "invitado", ...hobbies) {
  console.log(`Soy ${nombre}`);
  console.log("Hobbies:", hobbies.join(", ") || "ninguno");
}

presentar("Lucía", "leer", "correr");
presentar();

Callbacks

Un callback es una función que pasas a otra para que la ejecute más tarde (cuando termine una tarea, en cada elemento de un array, al hacer clic…).

function operar(a, b, callback) {
  return callback(a, b);
}

const resultado = operar(10, 4, (x, y) => x - y);
console.log(resultado); // 6

const numeros = [1, 2, 3];
numeros.forEach((n) => console.log(n * 2));
Nombres claros

Si la función hace algo concreto, nómbrala (calcularTotal, validarEmail). Las flechas anónimas van bien cuando el cuerpo es corto y el contexto (por ejemplo map) ya explica el qué.

Arrays y objetos

Los arrays guardan listas ordenadas. Los objetos guardan datos con nombre (clave → valor). Juntos cubren casi toda la estructura de datos del día a día en JS.

Arrays

const colores = ["rojo", "verde", "azul"];
console.log(colores[0]);      // "rojo"
console.log(colores.length);  // 3

colores.push("amarillo");     // añade al final
colores.pop();                // quita el último
colores.includes("verde");    // true

map, filter y reduce

Tres métodos que no mutan el array original (devuelven uno nuevo o un acumulado):

const numeros = [1, 2, 3, 4, 5];

const dobles = numeros.map((n) => n * 2);
// [2, 4, 6, 8, 10]

const pares = numeros.filter((n) => n % 2 === 0);
// [2, 4]

const suma = numeros.reduce((acum, n) => acum + n, 0);
// 15

console.log(dobles, pares, suma);
MétodoQué hace
mapTransforma cada elemento → nuevo array del mismo tamaño.
filterSe queda solo con los que cumplen una condición.
reduceReduce la lista a un solo valor (suma, objeto, string…).

Objetos

const producto = {
  id: 1,
  nombre: "Teclado",
  precio: 25.5,
  enStock: true,
};

console.log(producto.nombre);
console.log(producto["precio"]);

producto.precio = 22;
producto.categoria = "periféricos";

const { nombre, precio } = producto; // desestructuración
console.log(nombre, precio);

Arrays de objetos

const tareas = [
  { id: 1, texto: "Estudiar JS", hecha: false },
  { id: 2, texto: "Hacer ejercicio", hecha: true },
];

const pendientes = tareas.filter((t) => !t.hecha);
const titulos = tareas.map((t) => t.texto);
console.log(pendientes, titulos);

JSON

JSON es un formato de texto para intercambiar datos. En JS conviertes con JSON.stringify (objeto → texto) y JSON.parse (texto → objeto).

const usuario = { nombre: "Nora", edad: 28 };
const texto = JSON.stringify(usuario);
console.log(texto); // '{"nombre":"Nora","edad":28}'

const otraVez = JSON.parse(texto);
console.log(otraVez.nombre); // "Nora"
JSON no es lo mismo que un objeto JS

En JSON las claves van entre comillas dobles, no hay funciones ni undefined, y no admite comentarios. Es el formato típico de las APIs REST.

El DOM: leer y cambiar la página

El DOM (Document Object Model) es la representación en árbol del HTML que el navegador construye. Con JavaScript puedes seleccionar nodos y cambiar su texto, atributos y estilos.

HTML de ejemplo

<!DOCTYPE html>
<html lang="es">
<head>
  <meta charset="utf-8">
  <title>DOM</title>
</head>
<body>
  <h1 id="titulo">Hola</h1>
  <p class="aviso">Mensaje inicial</p>
  <button id="btn">Cambiar</button>
  <ul id="lista"></ul>
  <script src="app.js"></script>
</body>
</html>

Seleccionar elementos

const titulo = document.querySelector("#titulo");
const aviso = document.querySelector(".aviso");
const boton = document.querySelector("#btn");
const lista = document.querySelector("#lista");

// Varios a la vez:
const todosLosLi = document.querySelectorAll("li");
MétodoQué devuelve
querySelector(css)El primer elemento que coincida (o null).
querySelectorAll(css)Una lista (NodeList) de todos los que coinciden.
getElementById("id")Equivalente a querySelector("#id").

Texto, HTML y atributos

titulo.textContent = "DOM en acción";
aviso.textContent = "Texto seguro (no interpreta HTML)";

// innerHTML interpreta etiquetas; úsalo solo con contenido de confianza
lista.innerHTML = "<li>Uno</li><li>Dos</li>";

boton.setAttribute("disabled", "true");
boton.removeAttribute("disabled");
console.log(boton.getAttribute("id")); // "btn"
Cuidado con innerHTML y datos del usuario

Si pegas en innerHTML texto que escribió otra persona, puedes abrir la puerta a XSS (código malicioso en tu página). Para texto plano usa siempre textContent.

Estilos y clases

titulo.style.color = "crimson";
titulo.style.fontSize = "2rem";

aviso.classList.add("destacado");
aviso.classList.remove("destacado");
aviso.classList.toggle("oculto");
Prefiere clases CSS

Cambiar muchas propiedades con .style ensucia el JS. Mejor define clases en CSS y actívalas con classList.

Crear elementos

const li = document.createElement("li");
li.textContent = "Nuevo ítem";
lista.appendChild(li);

Eventos

Un evento es algo que ocurre en la página: un clic, una tecla, el envío de un formulario, el scroll… Con addEventListener te suscribes y reaccionas.

Clic en un botón

<button id="contador">Clics: 0</button>
<script src="app.js"></script>
const btn = document.querySelector("#contador");
let clics = 0;

btn.addEventListener("click", () => {
  clics++;
  btn.textContent = `Clics: ${clics}`;
});

Formularios y submit

En un <form>, el evento submit se dispara al enviar. Llama a event.preventDefault() si no quieres que la página se recargue.

<form id="form-saludo">
  <label>
    Nombre
    <input type="text" name="nombre" required>
  </label>
  <button type="submit">Saludar</button>
</form>
<p id="salida"></p>
const form = document.querySelector("#form-saludo");
const salida = document.querySelector("#salida");

form.addEventListener("submit", (event) => {
  event.preventDefault();
  const datos = new FormData(form);
  const nombre = datos.get("nombre");
  salida.textContent = `Hola, ${nombre}`;
  form.reset();
});

Teclado e input

const campo = document.querySelector('input[name="nombre"]');

campo.addEventListener("input", () => {
  console.log("Escribiste:", campo.value);
});

document.addEventListener("keydown", (event) => {
  if (event.key === "Escape") {
    console.log("Pulsaste Escape");
  }
});
event.target

Dentro del manejador, event.target es el elemento que originó el evento. Útil cuando un solo listener en un padre atiende muchos hijos (delegación de eventos).

document.querySelector("#lista").addEventListener("click", (event) => {
  if (event.target.matches("li")) {
    event.target.classList.toggle("hecho");
  }
});

Asincronía, promesas y fetch

Algunas tareas tardan: pedir datos a internet, leer un archivo, esperar un temporizador. JavaScript no se queda “congelado”: usa asincronía. Hoy el estilo más legible es async/await sobre promesas.

Qué es una promesa

Una promesa representa un valor que estará disponible en el futuro: pendiente, cumplida (fulfilled) o rechazada (rejected).

const espera = (ms) =>
  new Promise((resolve) => {
    setTimeout(() => resolve(`Pasaron ${ms} ms`), ms);
  });

espera(1000).then((mensaje) => console.log(mensaje));

async / await

async function demo() {
  try {
    const mensaje = await espera(500);
    console.log(mensaje);
  } catch (error) {
    console.error("Falló:", error);
  }
}

demo();
Solo await dentro de async

Una función marcada con async siempre devuelve una promesa. Usa try/catch alrededor de los await para capturar errores.

fetch API

fetch pide un recurso por HTTP y devuelve una promesa. Comprueba response.ok antes de confiar en el cuerpo.

async function cargarUsuarios() {
  try {
    const response = await fetch("https://jsonplaceholder.typicode.com/users");
    if (!response.ok) {
      throw new Error(`HTTP ${response.status}`);
    }
    const usuarios = await response.json();
    console.log(usuarios[0].name);
  } catch (error) {
    console.error("No se pudo cargar:", error.message);
  }
}

cargarUsuarios();
// Enviar JSON (POST)
async function crearPost(titulo, cuerpo) {
  const response = await fetch("https://jsonplaceholder.typicode.com/posts", {
    method: "POST",
    headers: { "Content-Type": "application/json" },
    body: JSON.stringify({ title: titulo, body: cuerpo, userId: 1 }),
  });
  return response.json();
}
CORS y APIs reales

Desde el navegador solo puedes llamar a APIs que lo permitan (CORS). Si tu petición falla por eso, no es un bug de tu fetch: el servidor no acepta orígenes ajenos. En desarrollo a veces usas un proxy o trabajas desde Node.

Módulos y npm

Cuando el proyecto crece, partes el código en archivos. Los módulos ES usan import / export. npm es el gestor de paquetes de Node: instala librerías y ejecuta scripts definidos en package.json.

export e import

export function sumar(a, b) {
  return a + b;
}

export const PI = 3.1416;

export default function restar(a, b) {
  return a - b;
}
import restar, { sumar, PI } from "./math.js";

console.log(sumar(2, 3));
console.log(restar(10, 4));
console.log(PI);

En el navegador, el script de entrada debe declararse como módulo:

<script type="module" src="app.js"></script>
Módulos y file://

Abrir el HTML con doble clic a veces falla con módulos por restricciones del navegador. Sirve la carpeta con un servidor local (extensión Live Server, o npx serve).

package.json y npm

En una carpeta de proyecto:

npm init -y
npm install lodash
npm install --save-dev prettier
{
  "name": "mi-proyecto",
  "version": "1.0.0",
  "type": "module",
  "scripts": {
    "start": "node app.js",
    "format": "prettier --write ."
  },
  "dependencies": {
    "lodash": "^4.17.21"
  },
  "devDependencies": {
    "prettier": "^3.0.0"
  }
}

Con "type": "module", Node trata los .js como módulos ES. Ejecuta scripts así:

npm start
npm run format
No subas node_modules

Esa carpeta es enorme y se regenera con npm install. Añádela a .gitignore. Sí sube package.json y, si existe, package-lock.json.

Depurar con las DevTools

Cuando algo falla, las herramientas de desarrollador del navegador (F12) te ahorran horas de adivinar. Tres sitios clave: Consola, Código / Sources y Red / Network.

Consola

  • console.log(valor) — inspecciona datos.
  • console.table(array) — tablas legibles para arrays de objetos.
  • console.error(...) — destaca fallos.
  • Los errores en rojo suelen indicar archivo y número de línea: haz clic para saltar al código.
const usuarios = [
  { id: 1, nombre: "Ada" },
  { id: 2, nombre: "Alan" },
];
console.table(usuarios);

Breakpoints (puntos de interrupción)

  1. Abre la pestaña Sources (o Depurador).
  2. Encuentra tu app.js y haz clic en el número de línea: aparece un marcador.
  3. Recarga o dispara el evento: la ejecución se pausa ahí.
  4. Inspecciona variables a la derecha, avanza línea a línea o continúa.

También puedes poner un breakpoint en el código:

function total(precios) {
  debugger; // la ejecución se pausa aquí si las DevTools están abiertas
  return precios.reduce((a, b) => a + b, 0);
}
Quita los debugger antes de publicar

Son útiles en desarrollo. No los dejes en producción: sorprenderían a quien abra las DevTools.

Pestaña Network

  • Ve cada petición: URL, método, estado (200, 404, 500…), tiempo.
  • Abre una fila → pestañas Headers, Preview, Response.
  • Filtra por Fetch/XHR para ver solo las llamadas de fetch.
Errores típicos al empezar

Cannot read properties of null suele significar que querySelector no encontró el elemento (typo en el id, o el script corre antes de que exista el HTML). Pon el <script> al final del body o usa type="module" / DOMContentLoaded.

Proyectos para practicar

La teoría se solidifica construyendo. Empieza pequeño, haz que funcione y luego mejora el diseño o añade detalles.

1. Contador

Tres botones: sumar, restar y reset. Practica DOM, eventos y estado con una variable.

let valor = 0;
const pantalla = document.querySelector("#valor");

document.querySelector("#mas").addEventListener("click", () => {
  valor++;
  pantalla.textContent = valor;
});
document.querySelector("#menos").addEventListener("click", () => {
  valor--;
  pantalla.textContent = valor;
});
document.querySelector("#reset").addEventListener("click", () => {
  valor = 0;
  pantalla.textContent = valor;
});

2. Lista de tareas (to-do)

Input + botón para añadir; cada tarea se puede marcar hecha o borrar. Usa un array de objetos y vuelve a pintar la lista (o crea/elimina nodos).

  • Bonus: guardar en localStorage con JSON.stringify.
  • Bonus: filtrar “todas / pendientes / hechas”.

3. Calculadora

Botones numéricos y operaciones. Practicas eventos, strings/números y un poco de lógica de estado (“operando actual”, “operador pendiente”).

4. Reloj digital

const reloj = document.querySelector("#reloj");

function actualizar() {
  const ahora = new Date();
  reloj.textContent = ahora.toLocaleTimeString("es-ES");
}

actualizar();
setInterval(actualizar, 1000);

5. Galería o modal

6. Consumir una API pública

Por ejemplo, lista de usuarios o posts con fetch, muestra un “cargando…”, maneja errores y pinta tarjetas en el DOM.

Orden sugerido

  1. Contador → eventos y DOM.
  2. Reloj → setInterval y fechas.
  3. Lista de tareas → arrays, renderizado y, si quieres, localStorage.
  4. Calculadora → lógica un poco más densa.
  5. API + fetch → asincronía real.
Cómo practicar bien

Escribe el enunciado en un comentario, implementa sin mirar soluciones, luego compara. Si usas IA, pídele que revise tu código o proponga mejoras después de tu primer intento: aprendes más.
